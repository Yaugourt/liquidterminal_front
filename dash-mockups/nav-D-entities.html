Nav D — Entity-first

the object graph

Liquid Terminal is not a set of pages, it is an explorer over a graph of objects: token, wallet, vault, validator, builder, perp DEX, outcome market, block, transaction. The left rail lists the classes of objects and their cardinality; the right rail is the Inspector of whatever object you are standing on: what it is, which edges leave it, and which objects you came through.

Filing rule ·  A page is either a class of objects or one object. Anything that is neither is a facet of a class (top bar) or a relation of the current object (right rail). Aggregates are not exempt: a class is itself an object, so /network, /hype and /home are singletons, and the /market hub disappears.

HyperCore / HyperEVM ·  never a branch of the tree. It is a property of an object (badge), a filter on a class (Tokens, Blocks), and one relation type (Core ⇄ EVM). HYPE and WHYPE are one object and its wrapper edge, not two nav entries.

MISSING KIT BLOCKS = MISSING PRIMITIVES

To build in src/components/common/

  • <InspectorRail> — the 280px right shell, three zones, sticky under the header.
  • <SubjectCard> — identity: avatar, name, canonical id, type badges, two micro stats, inline actions.
  • <RelationRow> — edge label, target, count. Not ModuleRow: no rank, no leaderboard semantics.
  • <TrailStack> — typed recently-visited objects + pinned chips.
  • <FacetBar> — MarketScopeBar promoted to a generic primitive (it exists in code, not in the kit).
  • <VenueBadge> — HyperCore / HyperEVM / Core+EVM / HIP-3. StatusBadge has no taxonomy variant.
  • <NavRail> — the sidebar itself is absent from the kit, and it needs a cardinality slot per class.

Killed or merged routes

  • /market hub — a page whose only job was to list pages. Its KPIs go to /network, its top-N modules to the class pages.
  • /hip4 + /market/hip4 → one /outcome, slug is the canonical id.
  • /explorer/address/[a] → /wallets/[a], merged with the tracker page. One object, one page.
  • /wiki/readlist (singular) → /wiki/readlists. Classes are plural everywhere.
  • /explorer/priority-fees → facet of Blocks. It is an attribute of block ordering, not a class.
  • /user → /profile, reached from the avatar. Account settings are not objects of the graph.
